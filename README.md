# Sensors Node

[Sensors Node](https://github.com/msmouni/sensors-node) is the MQTT-based sensor implementation for **ESP32-C3 microcontrollers**.

It uses the common sensor functionality provided by [libsensors](https://github.com/msmouni/libsensors) and communicates sensor measurements and commands using **MQTT over Wi-Fi**.

It provides a simple way to connect MCU-based sensors to the [Pi-Home](https://github.com/msmouni/pi-home-os) ecosystem.
